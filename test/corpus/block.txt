# Commands a guard must block. Format: <guard>[,option=value...] TAB <command>
# Options: timeout=<ms> (tool timeout, default 120000), platform=win32|posix (run only there).
# Each guard runs in the machine state it needs:
#   kill-guard, wait-guard  no other session, plenty of RAM
#   memory-guard            RAM nearly gone
#   port-guard              another Claude session holds every default dev port
#   checkout-guard          another live session works in the same repository, which has uncommitted changes
#   basics                  repository on main with a modified tracked file and an untracked file
# The option state=<name> runs one line in another state (see stateFor in harness.js).
# `#@ tool PowerShell` sends the lines below as PowerShell tool calls; `#@ config {json}` gives
# them a global config.json, until `#@ config none`.
# `<NL>` stands for a newline. A trailing TAB + `# todo: reason` marks a known miss in src/.
